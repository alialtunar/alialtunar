# Hi, I'm Ali 👋

AI Engineer. I build open-source [MCP](https://modelcontextprotocol.io) servers that give Claude (and any MCP client) new market-research skills, using public data and **no API keys**.

## 🧰 Keyless MCP servers

| Server | Question it answers | Install |
|---|---|---|
| [review-miner-mcp](https://github.com/alialtunar/review-miner-mcp) | What do users hate about competitor apps and games? (App Store + Steam reviews) | `uvx review-miner-mcp` |
| [pricing-time-machine-mcp](https://github.com/alialtunar/pricing-time-machine-mcp) | How did a SaaS pricing page change over the years? (Wayback Machine) | `uvx pricing-time-machine-mcp` |
| [hn-hiring-trends-mcp](https://github.com/alialtunar/hn-hiring-trends-mcp) | Which skills are tech companies hiring for, and which are rising? (HN Who is hiring) | `uvx hn-hiring-trends-mcp` |
| [model-price-radar-mcp](https://github.com/alialtunar/model-price-radar-mcp) | What does each LLM cost, and did it get cheaper? (OpenRouter + price history since 2023) | `uvx model-price-radar-mcp` |
| [launch-detector-mcp](https://github.com/alialtunar/launch-detector-mcp) | What is a company about to launch? (certificate transparency logs) | `uvx launch-detector-mcp` |

Add one to Claude Code with `claude mcp add <name> -- uvx <package>`. Find them in the [official MCP Registry](https://registry.modelcontextprotocol.io) under `io.github.alialtunar/`.
